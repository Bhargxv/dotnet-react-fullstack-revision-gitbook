# 23. TypeScript vs JavaScript

**Definition:**

> TypeScript is a superset of JavaScript that adds static type checking
> and other development-time features. TypeScript code is
> transformed/compiled into JavaScript before execution.

Mental model:

``` text
TypeScript
   ↓
Type checking / compilation
   ↓
JavaScript
   ↓
Browser / Node.js
```

Core JavaScript concepts remain:

``` text
functions
objects
arrays
callbacks
Promises
async/await
modules
closures
etc.
```

------------------------------------------------------------------------

## Main advantages of TypeScript

1.  Static type checking
2.  Better IntelliSense
3.  Safer refactoring
4.  Better documentation through types
5.  Easier maintenance of large codebases

------------------------------------------------------------------------

## Main disadvantages

1.  Additional syntax
2.  Learning curve
3.  Build/compile tooling
4.  Types can become unnecessarily complex if over-engineered

**Interview answer:**

> TypeScript adds static typing and development-time tooling to
> JavaScript. It is especially useful for large applications because it
> catches many mistakes during development and improves IDE support,
> maintainability and refactoring. It is ultimately transformed into
> JavaScript for execution.

------------------------------------------------------------------------

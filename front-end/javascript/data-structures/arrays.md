# 7. Arrays

Arrays store ordered collections.

``` js
const fruits = ["apple", "banana", "mango"];
```

Access:

``` js
fruits[0]; // "apple"
```

Useful operations:

``` js
fruits.push("orange");
fruits.pop();
fruits.length;
```

**Mutation warning:**

Methods such as `push`, `pop`, `splice` mutate the array.

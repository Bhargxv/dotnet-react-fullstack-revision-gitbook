# 4. Conditionals & Loops

Standard JavaScript control flow includes:

``` js
if (condition) {
    // ...
} else {
    // ...
}
```

Loops include:

``` js
for
while
do...while
for...of
for...in
```

Example:

``` js
for (let i = 0; i < 5; i++) {
    console.log(i);
}
```

`for...of` is commonly used for iterable values such as arrays:

``` js
for (const fruit of fruits) {
    console.log(fruit);
}
```
